一U盘使用指南

本节说明如何将网站保存到U盘，并在没有网络、没有安装任何开发软件的电脑上打开使用。

1.1 你需要保存什么

重要：保存两样东西

1. out 文件夹 — 这是成品网站，给别人看的。双击里面的「启动网站.bat」就能打开。

2. 整个「简历网址」文件夹 — 这是源代码，以后想改网站内容时需要。包含所有代码、数据、图片、视频。

两个都存到U盘。如果U盘空间不够，至少保存 out 文件夹。

1.2 如何构建网站（生成 out 文件夹）

如果你还没有 out 文件夹，或者你修改了网站内容后需要重新生成：

1双击「构建网站.bat」

在「简历网址」文件夹里找到 构建网站.bat，双击运行。会弹出一个黑色窗口，自动构建网站。

2等待构建完成

大约需要1-2分钟。完成后会自动弹出 out 文件夹。

3复制 out 文件夹到U盘

把整个 out 文件夹拖到U盘里。out 文件夹大小约 442MB（4个视频占大部分空间）。

1.3 在其他电脑上打开网站

1插入U盘

打开U盘里的 out 文件夹。

2双击「启动网站.bat」

浏览器会自动打开网站。不需要联网，不需要安装任何软件。

提示

推荐使用 Chrome 或 Edge 浏览器。如果双击 bat 文件后浏览器没有自动打开，可以手动双击 out 文件夹里的 index.html。

二网站内容修改指南

本节说明如何修改网站内容。所有内容都存在数据文件中，修改这些文件即可更新网站。

2.1 项目文件结构

简历网址/ ├── 构建网站.bat ← 双击构建网站 ├── 打开预览.bat ← 双击预览网站 ├── lib/data/ ← 【核心】所有内容数据 │ ├── projects.ts ← 项目/作品数据 │ ├── experience.ts ← 工作经历数据 │ ├── timeline.ts ← About页面成长时间线 │ ├── growth-log.ts ← AI成长日志数据 │ ├── site-config.ts ← 个人信息（邮箱、微信等） │ ├── abilities.ts ← 核心能力数据 │ └── workflow.ts ← AI工作流数据 ├── lib/i18n/ │ └── translations.ts ← 所有界面文字翻译 ├── public/ ← 所有媒体文件 │ ├── images/ ← 图片放这里 │ ├── videos/ ← 视频放这里 │ ├── audio/ ← 音乐放这里 │ └── resume/ ← 简历PDF放这里 ├── app/ ← 页面文件（一般不需要改） ├── components/ ← 组件文件（一般不需要改） └── scripts/ └── post-build.js ← 构建后处理脚本（勿动）

2.2 如何添加新作品

添加新作品只需要两步：1）把封面图片放到 public/images/projects/ 目录；2）在 projects.ts 里添加一条数据。

第1步：放封面图片

把项目封面图放到 public/images/projects/ 目录，命名建议用英文，例如 my-new-project-cover.png。

第2步：在 projects.ts 添加数据

打开 lib/data/projects.ts，在 projects 数组里添加一个新对象。以下是完整模板：

{
  id: "my-new-project",           // 唯一ID，用英文
  slug: "my-new-project",         // 网址路径，和id一样
  title: {
    zh: "我的新项目",
    en: "My New Project",
  },
  subtitle: {
    zh: "项目副标题",
    en: "Project Subtitle",
  },
  summary: {
    zh: "一句话简介。",
    en: "One-line summary.",
  },
  description: {
    zh: "详细描述，可以写多段。",
    en: "Detailed description.",
  },
  year: 2026,                       // 年份
  category: {
    zh: "AI视频创作",
    en: "AI Video Creation",
  },
  tags: ["AI视频", "AI"],         // 标签
  tools: ["ChatGPT", "Trae"],       // 使用的工具
  cover: {                            // 封面图片
    type: "image",
    url: "/images/projects/my-new-project-cover.png",
    alt: {
      zh: "项目封面",
      en: "Project Cover",
    },
  },
  videoUrl: "https://v.douyin.com/xxx/",  // 抖音链接（可选）
  videoFile: "/videos/my-new-project.mp4",  // 本地视频（可选）
  featured: false,                    // true=首页精选展示，false=仅作品列表
  createdAt: "2026-08-13",            // 创建日期
  process: [                          // 创作流程（可选）
    {
      step: 1,
      title: { zh: "故事概念", en: "Story Concept" },
      description: { zh: "描述", en: "Description" },
      tools: ["ChatGPT"],
    },
  ],
  challenges: [                      // 挑战与解决方案（可选）
    {
      title: { zh: "挑战标题", en: "Challenge" },
      problem: { zh: "问题描述", en: "Problem" },
      solution: { zh: "解决方案", en: "Solution" },
    },
  ],
}
字段说明

featured: 设为 true 会在首页精选作品区域展示，false 只在作品列表页展示。

videoUrl: 抖音等外部视频链接，会在详情页显示"观看视频"按钮。

videoFile: 本地视频文件路径，会在详情页显示视频播放器。把视频文件放到 public/videos/ 目录。

process / challenges / gallery: 都是可选字段，不需要的可以不写。

所有按钮、标题、描述等界面文字都在 lib/i18n/translations.ts 里。格式为：

三如何让新的AI Agent帮你修改网站

如果你以后换了一台电脑，或者没有了当前的聊天记录，你可以把这份指南和项目文件夹给一个新的AI Agent（如 Trae、ChatGPT、Claude 等），让它帮你修改网站。

3.1 需要准备什么

  1. 整个「简历网址」文件夹 — 包含所有源代码和数据
  2. 这份指南文档 — 让AI Agent了解项目结构
  3. 你的修改需求 — 具体想改什么内容

3.2 前置条件：安装 Node.js

新电脑需要安装 Node.js（免费）才能运行和构建网站：

  1. 访问 https://nodejs.org
  2. 下载 LTS 版本（长期支持版）
  3. 安装时一路"下一步"即可，默认配置不用改
  4. 安装完成后重启电脑

  summary、description、year、category、tags、tools、cover、videoUrl、videoFile、

3.5 技术栈信息（给AI Agent看）

  • 框架: Next.js 16 (静态导出模式 output: 'export')
  • UI: React 19 + Tailwind CSS v4
  • 动画: Framer Motion
  • 国际化: 自建 Context 双语系统 (zh/en)
  • 图片: next/image (unoptimized 模式)
  • 构建: npm run build → 生成 out/ 静态文件夹
  • 后处理: scripts/post-build.js 自动转换路径支持U盘部署
  • 部署: 静态文件，可放U盘通过 file:// 协议直接打开
注意事项

1. 修改数据文件时，注意 逗号 和 大括号 的配对，少一个逗号会导致构建失败。

2. 图片路径以 /images/ 开头，视频以 /videos/ 开头，不要写完整文件路径。

3. 所有文字都使用 { zh: "中文", en: "English" } 格式，两种语言都要填。

4. npm run build 会自动运行 post-build 脚本，生成的 out 文件夹已处理路径，可直接放U盘。

四常见问题

Q: 双击「打开预览.bat」后提示"端口被占用"

说明已经有一个预览服务器在运行。直接在浏览器打开 http://localhost:3000 即可。

Q: 双击「启动网站.bat」后网站打开是空白的

尝试用 Chrome 或 Edge 浏览器打开。也可以直接双击 out 文件夹里的 index.html。

Q: 构建失败怎么办

通常是数据文件格式错误。检查最近修改的文件里：逗号是否成对、大括号是否闭合、引号是否配对。如果无法解决，把错误信息发给AI Agent让它修复。

Q: 如何更换背景音乐

把新的MP3文件重命名为 bgm.mp3，放到 public/audio/ 目录覆盖原文件，重新构建即可。

Q: 如何更换简历PDF

把新的PDF文件重命名为 cheng-zhang-resume.pdf，放到 public/resume/ 目录覆盖原文件，重新构建即可。

Q: out 文件夹太大怎么办

442MB 主要是4个视频文件。如果U盘空间不够，可以删除 out/videos/ 里不需要的视频文件，同时把 projects.ts 中对应项目的 videoFile 字段删除。

Q: 以后换电脑了怎么继续开发

  1. 在新电脑安装 Node.js（nodejs.org，免费）
  2. 把「简历网址」文件夹从U盘复制到新电脑
  3. 在文件夹里打开命令行，运行 npm install 安装依赖
  4. 双击「打开预览.bat」开始预览
  5. 修改内容后双击「构建网站.bat」重新构建
